# Open item: auto-updating LinkedIn and YouTube on the "In the Media" page

**Owner:** client's tech team · **Page:** `docs/media.html` (live at `/media.html`) · **Status:** open (Nov 2026)

The page's "From our channels" section shows the 4 latest LinkedIn posts and 4 latest YouTube videos. Today both are a **snapshot** taken on 6 Nov 2026; they do not update on their own.

---

## 1. YouTube — make it update automatically (free)

The page has no YouTube script yet; it shows 4 fixed videos. To make it update:

1. In Google Cloud Console, create (or pick) a project and enable **YouTube Data API v3**.
2. Create an **API key**. Under *Application restrictions* choose **Websites** and add the site's domain (e.g. `https://<site-domain>/*`). Under *API restrictions* allow only **YouTube Data API v3**.
3. In `docs/media.html`, paste this just before `</body>`, with your key in place of `YOUR_API_KEY`, then commit and push:
   ```html
   <script>
   /* YouTube: show the channel's 4 latest uploads (falls back to the videos already on the page) */
   (function(){
     var KEY='YOUR_API_KEY', CHANNEL='UCIwuu7bLNnhcnVytOva9QIg';
     var g=document.querySelector('.ch-yt'); if(!g) return;
     fetch('https://www.googleapis.com/youtube/v3/playlistItems?part=snippet&maxResults=4&playlistId=UU'+CHANNEL.slice(2)+'&key='+encodeURIComponent(KEY))
       .then(function(r){ if(!r.ok) throw r; return r.json(); })
       .then(function(d){
         if(!d.items || !d.items.length) return;
         var esc=function(s){ var e=document.createElement('i'); e.textContent=s; return e.innerHTML; };
         g.innerHTML=d.items.map(function(it){ var s=it.snippet, id=s.resourceId.videoId;
           return '<a href="https://www.youtube.com/watch?v='+id+'" target="_blank" rel="noopener"><div class="ph"><img src="https://i.ytimg.com/vi/'+id+'/hqdefault.jpg" alt="" loading="lazy"><span class="play"><svg viewBox="0 0 24 24" fill="currentColor" aria-hidden="true"><path d="M7 4.5v15l13-7.5z"/></svg></span></div><h4>'+esc(s.title)+'</h4></a>';
         }).join('');
       }).catch(function(){});
   })();
   </script>
   ```

The page then fetches the channel's 4 latest uploads on every visit (1 API unit per visit; the free quota is 10,000 units/day). If the call fails, the videos already on the page stay. The cards keep the site's existing styling.

*Alternative (keeps the key private):* a scheduled GitHub Action that calls the same API once a day with the key stored as a repository secret, and writes the result into the page.

## 2. LinkedIn — options

LinkedIn has no public feed a website can read, so there is no free, maintenance-free option.

| Option | Cost | Notes |
|---|---|---|
| **Manual refresh** (current) | Free | Swap the 4 post IDs (below). A few minutes each time. |
| **LinkedIn Community Management API** | Free | Needs an approved LinkedIn developer app, a company-page admin to authorise it, and a server/GitHub Action to hold the token and refresh posts. Approval can take weeks. |
| **Feed widget service** (SociableKIT, Juicer, Elfsight…) | Free tiers with limits; paid ≈ $5–20/month | Paste their embed code into the LinkedIn section. Free tiers usually add branding or cap views; the styling won't fully match the site. Check current plans. |

### How to refresh the LinkedIn posts manually

In `docs/media.html`, the LinkedIn section (`id="ch-linkedin"`) has 4 tiles like:
```html
<div class="post" data-h='{"300": 655, "360": 696, "440": 796, "540": 921}' style="--h:696px">
  <iframe src="https://www.linkedin.com/embed/feed/update/urn:li:activity:7524083711403958272?collapsed=1" …></iframe>
</div>
```
1. On LinkedIn, open a new company post → **⋯ → Embed this post** → copy the number after `urn:li:activity:` (or `urn:li:share:`; use the URN exactly as given).
2. Replace the number in the `iframe src`.
3. Heights: `data-h` holds the post's height at 4 tile widths so the tile hugs the post. To measure, open `https://www.linkedin.com/embed/feed/update/<URN>?collapsed=1` in a browser at each width (300/360/440/540px) and note the page height, or simply set all four to a generous value (e.g. `700`): the tile will then show some empty space below shorter posts but still work.
4. Keep newest first, 4 posts max. Commit and push.
